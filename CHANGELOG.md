# Changelog

All notable changes to **Cursor RTL** are documented in this file.

## [1.0.0] - 2026-08-04

### Added

- Automatic RTL text direction in Cursor Agent chat, Composer, and Agents Window (Cursor 3 / Glass)
- Per-element RTL/LTR detection for mixed Arabic, English, numbers, and symbols
- Code blocks always remain LTR
- Status bar indicator with quick actions
- Safe backup of `main.js` before patching
- Auto re-apply after Cursor updates
- Local RTL script bundled beside Cursor `main.js` for reliable injection
